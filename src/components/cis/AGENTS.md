# Shared components

- Every date control is built on `JalaliCalendar` (`src/components/cis/jalali-calendar.tsx`: Saturday-first 6-week grid, month/year views, range mode, RTL keyboard); `JalaliDatePicker` (single, `onClear` for optional fields/filters) and the table range filter (presets + one range calendar) wrap it. Dates shown to users in tables, detail lists and timelines go through `DateText` (short date, hover card with long date/time/relative). Why: one look and behaviour for every date.
- Status colours come only from `statusTone` in `status-badge.tsx` (ordered groups: neutral → success → warning → destructive, fallback info; negated Persian words are excluded by look-arounds; `src/test/status-tone.test.ts` guards it); booleans render as `YesNo`; codes/counts use the `code`/`count` Badge variants. Why: identical badges everywhere.
- `TreeView` renders a flattened list of visible rows with one guide column per ancestor level, so lines stay continuous and the path to the selected node can be drawn in `--tree-line-active`; expansion is an explicit id set (first level open by default, ancestors of the selection auto-opened). Why: precise guide lines and simple keyboard navigation.
